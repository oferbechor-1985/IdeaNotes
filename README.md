# רעיונות – אפליקציית הערות מהירה (אנדרואיד)

לחיצה על האייקון פותחת ישר חלון קטן: כותבים, מקליטים או מכתיבים, ושומרים.

## איך מקבלים קובץ התקנה (APK)
1. ב-GitHub: New repository (אפשר פרטי) והעלאת כל תוכן התיקייה הזו (כולל התיקייה הנסתרת `.github`). הענף חייב להיקרא `main`.
2. לשונית **Actions** ← "Build APK" ← מחכים כמה דקות לסימן ✓ ירוק.
3. נכנסים לריצה, למטה ב-**Artifacts** מורידים `IdeaNotes-apk`, מחלצים ומעבירים את `app-debug.apk` לטלפון.
4. בטלפון פותחים את הקובץ ומאשרים "התקנה ממקור לא ידוע".

(אם ההרצה האוטומטית לא התחילה: Actions ← Build APK ← Run workflow.)

## איפה ההערות
`Android/data/com.ofer.ideanotes/files/notes/`
לכל הערה: קובץ `.txt` (תאריך, תגיות, טקסט) ואם יש הקלטה – קובץ `.m4a` עם אותו שם.
התיקייה פרטית (אפליקציות אחרות לא קוראות אותה), ונגישה מהמחשב בכבל USB.
במסך "ההערות שלי": צפייה (נעול בנעילת המסך), נגינה, מחיקה וייצוא zip.
